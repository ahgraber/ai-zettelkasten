# North Star

AI-Zettelkasten is a personal knowledge organizer built on the Zettelkasten principle that **connecting matters more than collecting**: knowledge lives as atomic notes — each a single idea carrying a stable identity and its sources — linked into a graph of typed relationships unique to its owner.
Notes come from across a personal knowledge store — ingested web resources, the owner's own annotations and standalone thoughts, and agent memories alike — and the graph is kept durable, idempotent, and duplicate-free, so an idea is captured once and survives re-ingestion and recovery.
The result is a corpus you can talk to and research over; it aims to be self-hostable on minimal infrastructure (no GPU, AI inference via external API services) so one person can own the entire system.
